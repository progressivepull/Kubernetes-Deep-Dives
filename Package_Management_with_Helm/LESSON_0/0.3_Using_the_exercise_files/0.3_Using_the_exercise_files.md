# 0.3 Using the exercise files

**Using the Helm Exercise Files**

The course is designed for hands-on learning. You will install Helm, run commands, create files, and build your own Helm charts while following the instructor.

**1. Hands-On Learning**

- Install Helm on your computer.

- Deploy third-party Helm charts.

- Use the Helm command-line tool to generate your own charts.

- Learn how to edit and customize the generated chart files.

**2. Exercise Files**

The instructor provides exercise files in a GitHub repository.

The files are organized by:

- Chapter number.

- Video number.

For example: Chapter 3, Video 3.

**3. Understanding Begin and End Files**

Each exercise folder may contain two versions of a file:

| **File** | **Description**                                               |
|----------|---------------------------------------------------------------|
| begin    | Original file before the lesson starts.                       |
| end      | Completed file after following the instructor's instructions. |

**Example:**

chapter-3/

video-3/

deployment-begin.yaml

deployment-end.yaml

- Use the begin file to follow along with the instructor.

- Use the end file to compare your work with the completed example.

**4. Important Notes**

- Some exercise files will be demonstrated during the videos.

- Other files may not be mentioned, but are still available.

- You can use the exercise files whenever you need help or want to compare your work.

**Key Takeaway**

The exercise files are a learning resource that helps you follow along, practice Helm commands, and compare your work with the instructor's completed examples.

**My recommendation:** Download the GitHub exercise repository before starting the hands-on lessons. Keep the begin and end files available so you can troubleshoot and verify your Helm configurations.
