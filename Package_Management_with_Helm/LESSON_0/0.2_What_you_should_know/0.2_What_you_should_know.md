# 0.2 What you should know

**What You Should Know Before Learning Helm**

Before starting this course, you should have a basic understanding of Kubernetes and the tools needed to work with it.

**Prerequisites**

1. **Kubernetes Basics**

- Understand Kubernetes fundamentals.

- Know what Pods, Deployments, and Services are.

2. **Kubernetes Cluster**

- Have access to a running Kubernetes cluster.

- Be comfortable using these commands:

```bash

kubectl get

kubectl describe
```

3. **Terminal and Unix Commands**

- Know how to use a terminal application.

- Understand basic commands:

```bash

mkdir # Create a directory

cd # Change directory

mv # Move or rename files

```

4. **Text Editor**

- Have a text editor such as Visual Studio Code (VS Code).

- Use it to view and edit Helm charts.

**Key Takeaway**

You do not need to be a Kubernetes expert to learn Helm. A basic understanding of Kubernetes, command-line tools, and YAML files is enough to get started.

**Preparation Checklist**

- Understand Kubernetes Pods.

- Understand Deployments and Services.

- Have access to a Kubernetes cluster.

- Know basic kubectl commands.

- Know basic Unix commands.

- Have VS Code or another text editor installed.

**My recommendation:** Since you're working with Kubernetes, Docker, and Podman on Windows, make sure your Kubernetes cluster is running and that kubectl get nodes works before starting the Helm exercises.
