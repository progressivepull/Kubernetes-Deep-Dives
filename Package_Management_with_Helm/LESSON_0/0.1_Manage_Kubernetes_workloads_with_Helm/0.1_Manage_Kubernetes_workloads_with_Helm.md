# 0.1 Manage Kubernetes workloads with Helm

**Introduction to Helm in Kubernetes**

Helm is a **package management tool for Kubernetes** that makes deploying and managing applications easier.

**Problems Helm Solves**

- **Multiple YAML files:** Deploying applications with many Kubernetes YAML files can be tedious and time-consuming.

- **Version control:** Helm allows teams to manage and track different versions of application deployments.

- **Rollback:** If an application update causes problems, Helm makes it easier to roll back to a previous working version.

**What You Will Learn**

1.  Understand the basics of Helm.

2.  Use Helm to deploy third-party software.

3.  Create your own Helm charts.

4.  Deploy applications using Helm charts.

5.  Upgrade existing Helm chart deployments.

6.  Manage application versions and roll back deployments.

**Key Terms**

| **Term** | **Description** |
|----|----|
| Helm | Package manager for Kubernetes. |
| Chart | A package containing Kubernetes application resources and configuration. |
| Release | An installed instance of a Helm chart. |
| Rollback | Returning an application to a previous version. |
| Upgrade | Updating an existing Helm deployment. |

**Main takeaway:** Helm simplifies Kubernetes application management by packaging multiple YAML files into reusable Helm charts, making deployments, upgrades, version management, and rollbacks easier.
