# Helm: Install a Helm Chart in Your Kubernetes Cluster

## 1. Introduction

Helm is a package manager for Kubernetes that helps site reliability engineers (SREs), platform engineers, and developers install and manage applications. This lesson introduces **Artifact Hub**, where you can discover and evaluate existing Helm charts before installing them.

**Key benefit:** Helm makes it easier to deploy complex applications without manually managing every Kubernetes YAML manifest.

## 2. What Is Artifact Hub?

[Artifact Hub](https://artifacthub.io/) is a CNCF-hosted catalog for discovering cloud-native packages. It lists more than Helm charts, including container images, Open Policy Agent (OPA) policies, and Krew plugins for `kubectl`.

Artifact Hub is primarily a **discovery catalog**; charts are generally retrieved from the repositories identified in their listings.

| Package type | Purpose |
| --- | --- |
| Helm charts | Package Kubernetes applications and configuration. |
| Container images | Package application code and dependencies. |
| OPA policies | Express policy and compliance rules. |
| Krew plugins | Extend `kubectl` functionality. |

## 3. Popular Helm Charts

| Chart | Purpose |
| --- | --- |
| `cert-manager` | Automates TLS certificate issuance and management. |
| `ingress-nginx` | Provides an NGINX-based Kubernetes Ingress controller. |
| `argo-cd` | Supports GitOps-based deployments. |
| `prometheus` | Collects monitoring metrics. |
| `redis` | Provides an in-memory data store. |
| `grafana` | Visualizes monitoring and operational data. |

## 4. Finding a Trustworthy Chart

When reviewing a chart on Artifact Hub, check its publisher and documentation. The instructor highlights these indicators for cert-manager:

| Indicator | Why it matters |
| --- | --- |
| CNCF project | Identifies the project's CNCF affiliation. |
| Verified publisher | Indicates publisher ownership has been verified by Artifact Hub. |
| Official package | Identifies a chart associated with the official project. |
| Signed package | Offers a way to check package authenticity. |
| Values schema | Describes and validates supported configuration values. |

These indicators are helpful, but do not replace security review, version checks, or testing.

## 5. What Is cert-manager?

**cert-manager** is a Kubernetes add-on that automates TLS certificate issuance and lifecycle management. It helps teams obtain and renew certificates, reduce manual administration, and avoid outages caused by expired certificates.

The training video mentions a Kubernetes **1.22 or higher** prerequisite for the chart shown. **This is version-specific training information, not a universal current requirement.** Verify compatibility in the documentation for the cert-manager version you select.

Official documentation: [cert-manager](https://cert-manager.io/docs/)

## 6. Inspecting an Artifact Hub Listing

A chart listing can include:

- **Overview:** Description of the software and chart.
- **Prerequisites:** Kubernetes and other requirements.
- **Installation:** Steps for deploying the chart.
- **Upgrade:** Guidance for moving between versions.
- **Templates:** Kubernetes resource templates, when available.
- **Default values:** Chart configuration defaults.
- **Values schema:** Supported configuration settings and validation.
- **Changelog:** Version history, when published.

## 7. Helpful Helm Commands

The lesson focuses on discovery and evaluation rather than completing an installation. These commands are useful for preparing to work with the cert-manager chart.

### Verify Helm

```bash
helm version --short
```

### List configured chart repositories

```bash
helm repo list
```

### Add the Jetstack repository

```bash
helm repo add jetstack https://charts.jetstack.io
```

### Refresh repository information

```bash
helm repo update
```

### Inspect chart metadata

```bash
helm show chart jetstack/cert-manager
```

### Inspect default chart values

```bash
helm show values jetstack/cert-manager
```

For actual installation, follow the current [official cert-manager Helm instructions](https://cert-manager.io/docs/installation/helm/), including any CRD and version-specific requirements.

## 8. Key Takeaways

1. Helm simplifies deploying and managing Kubernetes applications.
2. Artifact Hub is a catalog for finding cloud-native packages, including Helm charts.
3. Popular open-source projects publish reusable charts.
4. Publisher verification, official status, signatures, and documentation help evaluate trust.
5. cert-manager automates TLS certificate management in Kubernetes.
6. Chart listings provide prerequisites, installation instructions, configuration values, and sometimes changelogs.
7. Always confirm chart compatibility and installation instructions for the specific version you choose.
