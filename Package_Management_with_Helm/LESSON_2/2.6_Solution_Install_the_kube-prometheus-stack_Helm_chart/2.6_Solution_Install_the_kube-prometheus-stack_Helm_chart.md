# Solution: Install the kube-prometheus-stack Helm Chart

## Overview
This lesson demonstrates how to find, install, verify, and remove the **kube-prometheus-stack** Helm chart in a Kubernetes cluster. The challenge requires a Helm release named **`my-kps`** in a new namespace named **`challenge`**.

## What You Will Learn
- Find a Helm chart on [Artifact Hub](https://artifacthub.io/).
- Add and update a Helm chart repository.
- Install a chart into a specific Kubernetes namespace.
- Verify the Helm release and its pods.
- Uninstall the release and remove its Helm repository.

## Step-by-Step Commands

### 1. Find the chart
Search Artifact Hub for **kube-prometheus-stack** and select the chart maintained by **prometheus-community**. Review its installation instructions.

### 2. Create the namespace
```bash
kubectl create namespace challenge
```

### 3. Add the Prometheus Community Helm repository
```bash
helm repo add prometheus-community https://prometheus-community.github.io/helm-charts
helm repo update
```

### 4. Install the chart
```bash
helm install my-kps prometheus-community/kube-prometheus-stack --namespace challenge
```

- `my-kps` is the Helm **release name**.
- `prometheus-community/kube-prometheus-stack` identifies the **chart**.
- `--namespace challenge` selects the installation namespace.

### 5. Verify the installation
```bash
helm list --namespace challenge
kubectl get pods --namespace challenge -l release=my-kps
```

The instructor observed a successful first release revision and three matching pods. **Your pod count may differ** depending on chart version, cluster conditions, and which components are enabled. To inspect all resources and pod readiness, run:

```bash
kubectl get pods --namespace challenge
kubectl get all --namespace challenge
```

## Cleanup

### 6. Uninstall the Helm release
```bash
helm uninstall my-kps --namespace challenge
```

### 7. Remove the repository from your local Helm configuration
```bash
helm repo remove prometheus-community
helm repo list
```

### 8. Optional: Delete the challenge namespace
Only do this if you no longer need **any** resources in the namespace:

```bash
kubectl delete namespace challenge
```

**Important:** Uninstalling a Helm release may leave behind some resources, including certain CRDs or persistent data. Removing the local Helm repository does not uninstall resources from Kubernetes.

## Key Takeaways
1. **Artifact Hub** helps you discover and assess Helm charts.
2. A **Helm repository** makes charts available to your local Helm client.
3. A **Helm release** is a named installation of a chart.
4. **Namespaces** organize Kubernetes resources.
5. Always **verify** the release and workloads after installation.
6. Clean up by uninstalling the release and removing unused local repositories.

## Quick Command Reference

| Task | Command |
|---|---|
| Create namespace | `kubectl create namespace challenge` |
| Add repository | `helm repo add prometheus-community https://prometheus-community.github.io/helm-charts` |
| Update repositories | `helm repo update` |
| Install chart | `helm install my-kps prometheus-community/kube-prometheus-stack -n challenge` |
| List releases | `helm list -n challenge` |
| Check labeled pods | `kubectl get pods -n challenge -l release=my-kps` |
| Uninstall release | `helm uninstall my-kps -n challenge` |
| Remove repository | `helm repo remove prometheus-community` |
