# 2.7 Chapter Quiz

# Question 1

What is the best way to find the most reputable version of a Helm chart?

- **Filter for Official, Verified publisher and/or CNCF (Correct)**

- Find the chart with the greatest number of stars.

- Use the chart that appears first in the search results.

# Question 2

How is the helm installation command is structured?

- helm install \<release_name\>

- **helm install \<release_name\> \<repo/chart-name\> (Correct)**

- helm install

# Question 3

If you wanted to display high-level information about a chart (version, a brief description, and who maintains the chart) named linkedin-engine which helm command would you use?

- helm show linkedin-engine

- **helm show chart linkedin-engine (Correct)**

- helm show

- helm show values linkedin-engine
