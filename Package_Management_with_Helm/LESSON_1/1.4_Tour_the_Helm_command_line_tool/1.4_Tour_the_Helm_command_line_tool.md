# Helm CLI (Command Line Interface) — Summary

## 1. Verify Helm Installation

Helm is a package manager for Kubernetes that simplifies deploying and managing applications through **Helm charts**.

Run:

```bash
helm version --short
```

If a version appears, Helm is installed. If you see `helm: command not found`, review the installation steps or consult the [official Helm documentation](https://helm.sh/docs/).

## 2. Explore the Helm CLI

Run `helm` to display common actions, available commands, environment settings, and flags.

### Four Common Actions

| Command | Purpose |
|---|---|
| `helm search` | Search for charts in repositories or Artifact Hub. |
| `helm pull` | Download a chart locally. |
| `helm install` | Install a chart into Kubernetes as a release. |
| `helm list` | List installed Helm releases. |

Example:

```bash
helm list
```

The output includes columns such as NAME, NAMESPACE, REVISION, UPDATED, STATUS, CHART, and APP VERSION. If no releases appear, there are no releases in the selected namespace. Use `helm list --all-namespaces` to check the whole cluster.

## 3. Helm Environment Variables

Run:

```bash
helm env
```

This shows Helm's current environment settings. Empty quotation marks (`""`) indicate an unset or empty value in the output.

| Variable | Purpose |
|---|---|
| `HELM_CACHE_HOME` | Cache directory. |
| `HELM_CONFIG_HOME` | Configuration directory. |
| `HELM_DATA_HOME` | Application data directory. |
| `HELM_NAMESPACE` | Default namespace, if configured. |
| `HELM_DRIVER` | Release storage backend, if configured. |
| `KUBECONFIG` | Kubernetes configuration file path. |

Most Helm-specific variables begin with `HELM_`; `KUBECONFIG` is a Kubernetes variable Helm also uses.

## 4. Other Useful Helm Commands

| Command | Purpose |
|---|---|
| `helm create` | Scaffold a new chart. |
| `helm dependency` | Manage chart dependencies. |
| `helm upgrade` | Update an installed release. |
| `helm rollback` | Return to a previous release revision. |
| `helm uninstall` | Remove a release. |
| `helm status` | Inspect release status. |
| `helm show` | Display chart details. |
| `helm repo` | Manage chart repositories. |

## 5. Helm Flags

Flags change how commands behave.

```bash
# List releases in all namespaces
helm list --all-namespaces

# Install a local chart into an existing namespace
helm install myapp ./mychart --namespace production

# Preview an upgrade without applying it
helm upgrade myapp ./mychart --dry-run
```

## Key Takeaways

- `helm version --short` confirms Helm is available.
- `helm` displays command help.
- `helm list` shows releases in the current namespace.
- `helm env` displays environment settings.
- Helm charts package Kubernetes resources for repeatable deployments.
- Helm commands manage the release lifecycle: installation, upgrade, rollback, and removal.

**Bottom line:** Helm makes Kubernetes deployments more repeatable and easier to manage from the command line.
