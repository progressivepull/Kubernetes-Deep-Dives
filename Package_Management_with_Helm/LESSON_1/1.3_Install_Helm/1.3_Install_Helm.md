# 1.3 Install Helm

**Install Helm on Windows**

**With the Chocolatey package manager: **

1.  To install, run the command choco install kubernetes-helm. 

2.  Verify the installation worked by running the command Helm version --short. You should see information about your version of Helm. 

3.  To uninstall, run the command choco uninstall kubernetes-helm. 

**Install Helm on a Mac**

**With the Homebrew package manager: **

1.  To install, run the command brew install Helm.

2.  Verify the installation worked by running the command Helm version --short. You should see information about your version of Helm. 

3.  To uninstall, run the command brew uninstall. 

**Install Helm on Linux (Debian/Ubuntu) **

**With the Apt package manager:**

1.  To install, run the following commands: 

```bash

curl https://baltocdn.com/helm/signing.asc | gpg --dearmor | sudo tee /usr/share/keyrings/helm.gpg > /dev/null

```



```bash

sudo apt-get install apt-transport-https --yes

```



```bash

echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/helm.gpg] https://baltocdn.com/helm/stable/debian/ all main" | sudo tee /etc/apt/sources.list.d/helm-stable-debian.list

```

```bash

sudo apt-get update

```

```bash

sudo apt-get install helm

```

1.  Verify the installation worked by running the command helm version --short. You should see information about your version of Helm.

2.  To uninstall, run the command sudo apt-get remove helm.

**Other installation methods **

If you use another package manager, or you would like to install Helm from the binary release or a script, find more information in the [**Helm Docs: Install Helm**](https://helm.sh/docs/intro/install/).
