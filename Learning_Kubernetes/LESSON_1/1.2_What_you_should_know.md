# 1.2 What you should know 
  **Summary: What You Should Know Before Learning Kubernetes**

This lesson explains the basic prerequisites for taking a Kubernetes
course. You do not need to be an expert, but you should have some
familiarity with computers, terminal commands, containers, and text
editors.

**1. Prerequisites**


 | **Requirement**        | **Description**                                                           |
 | ---------------------- | ------------------------------------------------------------------------- |
 | Computer               | Windows, Linux, or macOS                                                  |
 | Internet access        | Required to download tools and access learning resources                  |
 | Terminal application   | Used to execute basic commands                                            |
 | Container knowledge    | Basic understanding of Docker or Podman                                   |
 | Text editor            | VS Code or another editor for modifying Kubernetes configuration files    |
 | Technical experience   | Beginner-level knowledge is sufficient                                    |
          


**2. Basic Terminal Commands**

You should understand simple Unix-style commands.


 |**Command**    |  **Purpose**                   | **Example**                 |
 | ------------- | ------------------------------ | --------------------------- |
 | mkdir         | Create a new directory         | mkdir kubernetes-project    |
 | cd            | Change directories             | cd kubernetes-project       |
 | ls            | List files and directories     | ls                          |
 | pwd           | Display the current directory  | pwd                         |


Example:

mkdir kubernetes-project

cd kubernetes-project

These commands create a project directory and navigate into it.

**3. Basic Understanding of Containers**

You should know what container technology does.

- Docker: A platform used to build, package, and run applications in
  containers.

- Podman: An alternative container engine.

- Containers: Lightweight, isolated environments that package
  applications and their dependencies.

- Kubernetes: A container orchestration platform that automates
  deployment, scaling, and management of containerized applications.

Key concept: Docker and Podman run containers, while Kubernetes
coordinates and manages containers across computing environments.

**4. Text Editor and Kubernetes Manifests**

A text editor such as Visual Studio Code (VS Code) is needed to create
and modify Kubernetes manifests.

Kubernetes manifests are typically YAML files that describe how
Kubernetes resources should be configured.

```
Example:
apiVersion: v1
kind: Pod
metadata:
name: my-first-pod
spec:
containers:
 - name: nginx
image: nginx:latest
```

This manifest defines a Kubernetes Pod containing an Nginx container.

**5. Key Takeaways**

1.  Kubernetes beginners do not need extensive technical experience.

2.  Windows, Linux, and macOS are supported learning environments.

3.  Basic terminal commands such as mkdir and cd are useful.

4.  Understanding Docker or Podman helps explain how Kubernetes works.

5.  VS Code can be used to create and edit Kubernetes YAML manifests.

6.  Kubernetes manages containerized applications, including deployment
    and scaling.

Main takeaway: To begin learning Kubernetes, you need a computer,
internet access, basic command-line skills, a text editor, and a
high-level understanding of containers. Advanced Docker or Kubernetes
knowledge is not required.
