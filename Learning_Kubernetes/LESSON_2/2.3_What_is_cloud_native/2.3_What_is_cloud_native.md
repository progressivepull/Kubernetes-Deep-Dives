# 2.3 What is cloud native

**Summary: What Is Cloud Native?**

**Cloud native** is an approach to building, deploying, and managing applications using cloud computing technologies to make them scalable, flexible, and easy to automate.

**Key Characteristics of Cloud Native**

- **Scalability:** Applications can scale up or down based on demand.

- **Automation:** Software deployment, testing, and infrastructure management can be automated.

- **Containers:** Package applications with their dependencies so they run consistently across environments.

- **Microservices:** Break applications into smaller, independent services.

- **Open source:** Many cloud native technologies are open-source projects.

- **Collaboration:** Developers and operations teams work together to deliver software faster.

**What Is the CNCF?**

The **Cloud Native Computing Foundation (CNCF)** is part of the Linux Foundation. Its mission is to make cloud native computing widely adopted by supporting open-source projects, communities, training, and conferences.

The CNCF classifies projects into three maturity levels:

- **Sandbox:** Early-stage or experimental projects.

- **Incubating:** Projects gaining adoption and demonstrating progress toward maturity.

- **Graduated:** Mature projects considered ready for broad production use.

**Important Cloud Native Technologies**

- **Kubernetes:** Automates container deployment, management, and scaling.

- **Helm:** Helps install and manage applications on Kubernetes.

- **Prometheus:** Monitors applications and collects metrics.

- **Linkerd:** A service mesh that helps manage communication between services.

**Traditional vs. Cloud Native**

| **Traditional approach** | **Cloud native approach** |
|----|----|
| Manual deployments | Automated deployments |
| Scaling often requires manual work | Scaling can be automated |
| Applications may be tightly coupled | Applications can use independent microservices |
| Infrastructure changes can be slow | Infrastructure can be managed through code and declarative APIs |

**Key Takeaway**

**Cloud native is a way of designing and operating applications for modern cloud environments.** Kubernetes is a major cloud native technology because it automates the deployment, scaling, and management of containerized applications.

**Remember:** Cloud native is the overall approach, containers package applications, and Kubernetes manages those containers.
