# 3.1 Install Docker on Windows

**Summary: Install Docker on Windows**

The lesson explains how to install **Docker Desktop on Windows 10** to prepare your computer for running a local Kubernetes cluster.

**Installation Steps**

1.  **Visit Docker Docs:** Open the official Docker Desktop installation page for Windows.

2.  **Download Docker Desktop:** Click the download button to download the installer.

3.  **Run the installer:** Open the downloaded file and approve the installation when prompted.

4.  **Create a shortcut:** Select the option to add a Docker Desktop shortcut to your desktop.

5.  **Complete installation:** Wait for the installation process to finish.

6.  **Restart Windows:** Restart your computer to complete the installation.

7.  **Launch Docker Desktop:** Open Docker Desktop and ensure it is running.

**Why Is Docker Needed?**

- **Docker** provides the container engine used to run containers.

- **Docker Desktop** makes Docker available on your Windows computer.

- Docker will help you prepare your environment for running a local Kubernetes cluster.

- The next lesson introduces **Minikube**, a tool that runs a Kubernetes cluster locally on your computer.

**Key Takeaway**

**Docker runs containers, while Minikube lets you run Kubernetes locally.** Installing Docker is an important step in preparing your computer for hands-on Kubernetes practice.
