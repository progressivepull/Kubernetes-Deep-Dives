# 3.5 Install minikube on Linux

**Summary: Install Minikube on Linux**

**1. What is Minikube?**

Minikube is a free, open-source tool that allows you to run a local Kubernetes cluster on your computer.

It is primarily used for:

- Learning Kubernetes concepts.

- Practicing Kubernetes commands.

- Developing and testing containerized applications.

- Running Kubernetes without paying for cloud infrastructure.

Important: Minikube is designed primarily for learning and development, not production environments.

**2. Prerequisites**

Before installing Minikube on Linux, you need:

| **Requirement** | **Description** |
|----|----|
| Linux operating system | Ubuntu, Debian, Fedora, or another supported distribution |
| Terminal | Used to execute Linux commands |
| Container runtime or driver | Docker or Podman, for example |
| Internet connection | Required to download Minikube |
| Hardware resources | Sufficient CPU, memory, and disk space |

**3. Install Minikube on Linux**

The following commands install the stable Minikube release for Linux systems using an x86-64 (AMD64) processor.

Step 1: Download Minikube

<span class="mark">curl -LO https://storage.googleapis.com/minikube/releases/latest/minikube-linux-amd64</span>

This command downloads the latest stable Minikube binary.

Step 2: Install Minikube

<span class="mark">sudo install minikube-linux-amd64 /usr/local/bin/minikube</span>

This command installs the Minikube executable into /usr/local/bin.

Step 3: Verify installation

<span class="mark">minikube</span>

If Minikube displays a list of available commands, the installation was successful.

You can also check the installed version:

<span class="mark">minikube version</span>

**4. Start a Kubernetes Cluster**

After installation, start Minikube using Docker:

<span class="mark">minikube start --driver=docker</span>

This creates and starts a local Kubernetes cluster.

Check its status:

<span class="mark">minikube status</span>

View the Kubernetes nodes:

<span class="mark">minikube kubectl -- get nodes</span>

**5. Common Minikube Commands**

| **Command**                  | **Purpose**                        |
|------------------------------|------------------------------------|
| minikube start               | Start a Kubernetes cluster         |
| minikube stop                | Stop the cluster                   |
| minikube status              | Check cluster status               |
| minikube dashboard           | Open the Kubernetes dashboard      |
| minikube version             | Display installed version          |
| minikube delete              | Delete the local cluster           |
| minikube kubectl -- get pods | List pods in the default namespace |

**6. Minikube vs. Production Kubernetes**

| **Feature** | **Minikube** | **Production Kubernetes** |
|----|----|----|
| Primary purpose | Learning and development | Running real applications |
| Infrastructure | Local computer | Cloud or data center |
| Cost | Free software; uses local resources | Infrastructure and operational costs |
| Scalability | Limited by local resources | Designed for larger workloads |
| Security | Development-focused configuration | Production-grade security configuration |
| Networking | Local networking capabilities | Advanced networking options |

**7. Key Takeaways**

1.  Minikube runs Kubernetes locally without requiring cloud infrastructure.

2.  Docker or Podman can provide the container environment needed to run Minikube.

3.  Installation involves downloading and installing the Minikube executable.

4.  Running minikube verifies that the executable is available.

5.  Running minikube start creates a local Kubernetes cluster.

6.  Minikube is excellent for learning, development, and testing but is not intended as a production Kubernetes platform.

Remember for exams:

- Minikube = Local Kubernetes cluster

- Docker/Podman = Container runtime

- minikube start = Create and start cluster

- minikube status = Check cluster

- minikube stop = Stop cluster

- minikube delete = Remove cluster

Main concept: Minikube provides an inexpensive and convenient way to learn Kubernetes by running a cluster directly on your Linux computer.
