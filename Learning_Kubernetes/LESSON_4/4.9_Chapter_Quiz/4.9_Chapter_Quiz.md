# 4.9 Chapter Quiz

## Question 1
Using the describe pod command, what will the event log show for a pod that has been running for a long time?

A. The event log will show as empty.

Correct
If a pod has been running for a while, Kubernetes will assume it is healthy and not show its events.

B. The command is not expected to show pod events.

Incorrect
This command can actually be used to review the events of a given pod.


C. The event log will show all events from launch.

Incorrect
The event log shows the events that Kubernetes is currently retaining for the pod, not necessarily all events since the pod was launched.
