# 4.9 Chapter Quiz

## Question 1
Using the describe pod command, what will the event log show for a pod that has been running for a long time?

**A. The event log will show as empty.**

Correct
If a pod has been running for a while, Kubernetes will assume it is healthy and not show its events.

B. The command is not expected to show pod events.

Incorrect
This command can actually be used to review the events of a given pod.


C. The event log will show all events from launch.

Incorrect
The event log shows the events that Kubernetes is currently retaining for the pod, not necessarily all events since the pod was launched.

## Question 5
Pod A with an IP address of 172.17.0.3 is running a web server. On pod B on the cluster, running wget 172.17.0.3 results in a refused connection. What is one immediate thing to check?

A. Pod B is exposing port 80.

Incorrect
Pod B is the client making the request. It does not need to expose any port to initiate an HTTP connection to Pod A.

B. Pods A and B are exposing port 3000.

Incorrect
wget 172.17.0.3 does not attempt to connect to port 3000. It uses port 80 by default. Port 3000 is irrelevant unless you explicitly specify:

C. Pod A is exposing port 8080.

Incorrect
If the web server is listening on port 8080, then:

```bash
wget 172.17.0.3
```
would still fail because it is trying port 80.

**D. Pod A is exposing port 80.**
Correct
