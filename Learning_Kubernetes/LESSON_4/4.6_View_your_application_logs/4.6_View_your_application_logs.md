# 4.6 View your application logs

**Viewing Your Application Logs in Kubernetes**

Kubernetes allows you to view application logs to monitor activity and troubleshoot problems.

**Steps to View Application Logs**

**1. List pods in the development namespace**

bash

kubectl get pods -n development

**2. Copy the name of the pod** whose logs you want to inspect.

**3. View the pod's application logs**

bash

kubectl logs \<pod-name\> -n development

This command displays the logs generated by the application running inside the pod.

**Understanding Application Logs**

- Logs show application activity and events.

- They help identify errors and troubleshoot application issues.

- They can show incoming HTTP requests and other application activity.

- To see activity, inspect the pod that received your earlier BusyBox wget request.

**Important Commands to Remember**

| **Command**                              | **Purpose**              |
|------------------------------------------|--------------------------|
| kubectl get pods -n development          | List application pods    |
| kubectl logs \<pod-name\> -n development | Display application logs |

**Key Takeaways**

- kubectl logs is used to view application logs in Kubernetes.

- Logs help developers understand what an application is doing.

- You can use logs to investigate application errors and verify incoming requests.

- Choosing the correct pod is important when troubleshooting.

**Remember these three Kubernetes troubleshooting commands:**

1.  kubectl describe pod – View pod details and events.

2.  kubectl exec – Execute commands inside a running container.

3.  kubectl logs – View application logs.
