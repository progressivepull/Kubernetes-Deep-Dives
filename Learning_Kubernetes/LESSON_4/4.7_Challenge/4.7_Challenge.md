# 4.7 Challenge

**Chapter 3 Kubernetes Challenge – Create a Deployment**

The challenge is to create a Kubernetes Deployment named **quote-service** using a YAML file called quote.yaml.

**Deployment Requirements**

| **Setting**     | **Required value**   |
|-----------------|----------------------|
| YAML file       | quote.yaml           |
| Deployment name | quote-service        |
| App label       | quote-service        |
| Namespace       | development          |
| Container name  | quote-container      |
| Replicas        | 2                    |
| Container image | datawire/quote:0.5.0 |
| Container port  | 8080                 |

**Step 1: Create** quote.yaml

Use the following configuration:

yaml

apiVersion: apps/v1

kind: Deployment

metadata:

name: quote-service

namespace: development

labels:

app: quote-service

spec:

replicas: 2

selector:

matchLabels:

app: quote-service

template:

metadata:

labels:

app: quote-service

spec:

containers:

\- name: quote-container

image: datawire/quote:0.5.0

ports:

\- containerPort: 8080

**Step 2: Deploy the application**

bash

kubectl apply -f quote.yaml

**Step 3: Verify the deployment**

Check that the deployment was created:

bash

kubectl get deployments -n development

Check the pods:

bash

kubectl get pods -n development

You should see two quote-service pods running.

**Step 4: Optional Challenge – Test with BusyBox**

Use BusyBox to test whether the quote application accepts traffic from inside the Kubernetes cluster.

1\. Find the quote-service pod IP addresses:

bash

kubectl get pods -n development -o wide

2\. Enter your BusyBox container:

bash

kubectl exec -it \<busybox-pod-name\> -- /bin/sh

3\. Test the application using port 8080:

bash

wget -qO- \<pod-ip-address\>:8080

4\. Exit BusyBox:

bash

exit

**Key Takeaways**

- Create Kubernetes deployments using YAML manifests.

- Configure replicas, labels, namespaces, containers, and ports.

- Deploy resources using kubectl apply.

- Verify deployments and pods using kubectl get.

- Use BusyBox and wget to test internal application connectivity.

**Main objective:** Successfully deploy two replicas of the quote-service application in the development namespace and optionally verify that the application responds to HTTP requests.
