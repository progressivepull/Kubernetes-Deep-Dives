# Question 1

You get the error shown below upon pushing the image docker.io/hello/world into the Docker Hub: *unauthorized: authentication required* You confirmed that you were able to login as the hello user on the Docker Hub website. Which of these choices best explains the cause for this error?

- A. You need to run docker tag before pushing images.

- B. You need to run docker login first with either your personal access token or your account password.

- **C. You need to run docker login first with your personal access token.** **Correct**

> You can ONLY use your personal access token when logging into the Docker Hub with \`docker login\`.

- D. A firewall is blocking access to the Docker Hub.

# Question 3

You want to publish a container image that you created to your company's internal registry. You are already logged into the registry on your computer. Which of these command sequences will accomplish this?

- A. docker build docker tag docker login docker push

- B. docker tag docker build docker login docker push

- C. docker tag docker build docker push

- **D. docker build docker tag docker push**

> **Correct**
>
> You need to build the image before you can tag it, and you need to tag it with the URL of the image registry before you can push.

# Question 4

A colleague used ***docker run*** to start a container called "test-container" from a container image in your Team Foundation Server repository. However, they are unable to find it while running docker ps and are asking you for ***help***.

You confirmed that they used the ***--name*** argument to correctly name the container that they started.

Which of these options best summarizes why this might have happened?

- A. They should have run docker container run instead of docker run.

- B. The VM underlying Docker Desktop is not started.

- C. They used docker build instead of docker run.

- **D. They used the --rm command line flag to remove the container after it was run.**

> **Correct**
>
> --rm removes containers after the command they are configured to run terminates.
