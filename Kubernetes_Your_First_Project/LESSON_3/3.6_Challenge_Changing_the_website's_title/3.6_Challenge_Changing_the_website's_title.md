# 3.6 Challenge Changing the website's title

## **"Challenge: Changing the website's title"** module based on the transcript provided.

**🎯** The Objective

You need to verify a modified version of the **Explore California** application inside a new container. The updates include:

- An updated webpage title in index.htm that reads: *"Tours, Adventure, Travel, Explore California"* (changed from *"Welcome to Explore California"*).

- A new security configuration requiring Nginx to serve the site static assets out of a custom path: **/usr/share/nginx/website**.

Your job is to build a new container image tagged as **explorecalifornia.com-new** and spin up a container that successfully serves the updated title at localhost:5000.

## **🛠️** Provided Constraints & Tips

- **Git Branch Alignment:** All source files, directories, and customized assets are located inside the **03_06b** Git branch.

- **Configuration Dependency:** Ensure your image build process utilizes the custom nginx.conf file present in this specific branch to implement the correct custom path.

- **No Volumes Allowed:** The changes must be permanently baked into the image layers. You **should not** dynamically map files using the volume (-v) flag during the run step.

**💡** Solution Strategy Blueprint

To successfully solve this lab challenge, your execution workflow should follow these steps:

## 1.  **Switch Branch:** Ensure you are working with the correct challenge files:

```bash

git checkout 03_06b

```

## 2.  **Inspect or Modify the Containerfile:** Ensure the file copies the website folder to the custom cybersecurity directory:

```dockerfile

FROM nginx:alpine
COPY nginx.conf /etc/nginx/nginx.conf
COPY website /usr/share/nginx/website
EXPOSE 80

```

## 3.  **Build the Challenge Image:**

```bash

podman build -t explorecalifornia.com-new .

```

## 4.  **Run the Container:** Expose the internal port to port 5000 on your host system:

```bash

podman run --rm --name explore-california-challenge -p 5000:80 explorecalifornia.com-new

```
