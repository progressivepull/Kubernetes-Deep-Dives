 # 0.1 Your first project on Kubernetes
 
 This course is a beginner-friendly introduction to Kubernetes and cloud cluster administration that requires no prior experience with the platform.

## Key Takeaways

* No Prerequisites: You do not need prior Kubernetes experience; terminal commands will be explained as you go.
* Hands-On Cloud Labs: You will practice deploying a sample project ("Explore California") to the cloud using both AWS and Azure (requires creating accounts).
* Course Support: A handout with setup links is provided, and recommendations for advanced follow-up courses will be shared later.
