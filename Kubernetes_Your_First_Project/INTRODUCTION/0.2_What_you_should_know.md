 # 0.2 What you should know
 
 This course teaches Kubernetes basics and cluster administration fundamentals with no prior experience required.

# 🛠️ Prerequisites & Skills

* **Terminal navigation:** Some familiarity helps, but commands will be explained along the way.
* **Cloud accounts:** You will need to create AWS and Azure accounts to follow along with cloud deployments.
* **Setup resources:** A handout with setup links is provided to help you get started.

# 🏛️ Course Focus

* **Hands-on project:** You will deploy a project called **Explore California** into cloud Kubernetes clusters.
* **Next steps:** The next video covers why Explore California is moving to Kubernetes.
* **Future learning:** Additional course recommendations will be provided to expand your knowledge later.
