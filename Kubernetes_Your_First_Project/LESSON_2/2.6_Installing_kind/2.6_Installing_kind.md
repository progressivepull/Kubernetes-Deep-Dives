# 2.6 Installing kind

**Installing Kind (Kubernetes in Docker)**

This lesson explains how to install Kind (Kubernetes in Docker) on macOS and Windows.

Kind is a tool that creates local Kubernetes clusters using containers. It allows you to practice Kubernetes without paying for cloud services.

**1. Install Kind on macOS**

1.  Open your browser.

2.  Visit [<u>Kind official website</u>](https://kind.sigs.k8s.io/?utm_source=chatgpt.com).

3.  Click Quick Start.

4.  Select Install from release binaries.

5.  Copy the macOS installation command.

6.  Open Terminal (Command + Space, then type Terminal).

7.  Paste and execute the installation command.

The installation process:

- Downloads the correct Kind version for your Mac (Apple Silicon or Intel).

- Makes the downloaded file executable.

- Moves Kind into /usr/local/bin.

If necessary, use sudo to move the file because administrator permissions are required.

**2. Verify Kind on macOS**

Run:

```bash
kind --version
```

If a version number appears, Kind is successfully installed.

**3. Install Kind on Windows**

1.  Open [<u>Kind official website</u>](https://kind.sigs.k8s.io/?utm_source=chatgpt.com).

2.  Click Quick Start.

3.  Select Install from release binaries.

4.  Find and copy the Windows installation commands.

5.  Open PowerShell.

6.  Paste the commands and execute them.

The installation process:

- Downloads the Kind executable using curl.

- Moves the executable into your Apps directory.

For this course, the destination directory is:

```bash
\$env:USERPROFILE\Apps
```

This is the directory we created and added to PATH during the Windows preparation lesson.

**4. Verify Kind on Windows**

Run:

```bash
kind --version
```

If you see a version number, Kind is installed correctly.

**Important Commands to Remember**

| **Command** | **Purpose** |
|----|----|
| kind --version | Checks the installed Kind version |
| curl | Downloads the Kind executable |
| sudo | Runs commands with administrator privileges on macOS |
| Move-Item | Moves files in PowerShell |
| \$env:USERPROFILE\Apps | Windows application installation directory |

**Final Checklist**

- Install Kind on macOS or Windows.

- Download the correct executable.

- Move Kind into a directory included in PATH.

- Run kind --version.

- Confirm that a version number appears.

**Main takeaway:** Kind is installed and ready to create local Kubernetes clusters using your Podman container environment.
