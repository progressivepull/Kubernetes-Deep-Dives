# 2.2 Preparing Windows machines

**Preparing Windows for Kubernetes Development**

Before installing Podman Desktop and the Kubernetes tools, Windows needs some preparation.

**1. Create an Apps Directory**

Open PowerShell as Administrator and run:

```powershell

New-Item -ItemType Directory \$env:USERPROFILE\Apps
```

This creates an Apps folder in your Windows user directory to store applications.

**2. Add Apps to the PATH Environment Variable**

Run:

```powershell

setx /m PATH "\$env:PATH;\$env:USERPROFILE\Apps"
```

This allows Windows to find applications in the Apps directory without typing the full directory path.

**3. Enable Windows Subsystem for Linux (WSL)**

Run:

```powershell

Enable-WindowsOptionalFeature -Online -FeatureName VirtualMachinePlatform -All -NoRestart
```

This enables the Virtual Machine Platform feature required for WSL.

**4. Install WSL**

Run:

```powershell

wsl –install
```

This installs Windows Subsystem for Linux.

**5. Restart Windows**

Run:

```powershell

Restart-Computer -Force
```

Your computer will restart immediately.

**Final Checklist**

- Create C:\Users\YourUsername\Apps.

- Add the Apps directory to PATH.

- Enable Virtual Machine Platform.

- Install WSL.

- Restart your computer.
