# 2.11 Configuring Azure access interactively

How to configure **Azure CLI access interactively** based on the transcript provided.

# **🔑 Login Methods Overview**

The Azure CLI offers two common authentication routes:

- **Interactive Login:** Very easy to set up using a browser, making it perfect for local development on personal machines.

- **Service Principal:** Functions like a service account mapped to specific subscription roles, designed strictly for automated CI/CD pipelines where a browser is unavailable.

# **🚀 Step-by-Step Interactive Login Guide**

Running commands like az group list before authenticating will return an error stating that you must log in first.

## **Method A: Standard Web Popup (Windows Default)**

1.  Open your terminal and execute:

```bash

az login

```

2. A browser window will automatically pop up.

3. Choose your account type (Microsoft account, work account, or school account) and enter your credentials.

4. Click **Continue** when asked to confirm the sign-in request to the Azure CLI.

## **Method B: Device Code Login (Mac / Headless Environments)**

Because the automated popup does not occur on macOS, you must use the device authorization flow:

1.  Open your terminal and run:

```bash

az login --use-device-code

```

2.  The terminal will generate a unique code and provide a URL (e.g., microsoft.com).

3.  Open the URL in your web browser, paste the copied code, and complete your login.

# **🎯 Finalizing the Connection**

1.  Once authenticated in the browser, return to your terminal. You will see a list of available Azure subscriptions linked to your account.

2.  If prompted with multiple subscriptions, type the number corresponding to the subscription you want to set as active (e.g., 1).

3.  Verify the connection by running:

```bash

az group list

```

This will now successfully display a JSON array of the resource groups inside your active Azure subscription.
