# 2.8 Installing AWS CLI and Azure CL

**💻 macOS Installation (Using Homebrew)**

Because manual installation can fail on Apple Silicon Macs, the recommended method is using the Homebrew package manager.

1.  **Install Homebrew:** Go to brew.sh, copy the installation command, paste it into the Terminal, and enter your password.

2.  **Add to Path:** Once finished, copy and run the three commands provided at the end of the installation to add Homebrew to your system path. Verify by typing brew.

3.  **Install CLIs:** Run the following single command to install both tools:

```bash

brew install azure-cli awscli

```

4.  **Verify:** Confirm successful installation by checking the versions:

    - aws --version

    - az --version

------------------------------------------------------------------------

**🪟 Windows Installation (Using WinGet)**

Windows utilizes its built-in package manager, WinGet, via PowerShell.

1.  **Open PowerShell:** Press Windows Key + R, type PowerShell, and hit Enter.

2.  **Install AWS CLI:** Run the following command and type Y to agree to the terms:

```powershell

winget install --exact --id Amazon.AWSCLI

```

3.  **Install Azure CLI:** Run the following command:

```powershell

winget install --exact --id Microsoft.AzureCLI

```


4.  **Verify:** Restart your terminal if necessary, then confirm the installations by checking the versions:

    - aws --version

    - az --version
