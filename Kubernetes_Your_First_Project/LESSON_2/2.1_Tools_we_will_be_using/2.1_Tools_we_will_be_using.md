# 2.1 Tools we will be using

**Tools Needed for the Kubernetes Course**

The course will use several tools to build, manage, and deploy Kubernetes clusters locally and in the cloud.

**1. Local Container Management**

- Podman Desktop: Runs and manages containers on your computer.

- Includes Podman, a container runtime.

- Similar to Docker Desktop and Rancher Desktop.

**2. Local Kubernetes Clusters**

- Kind (Kubernetes in Docker): Creates local Kubernetes clusters using containers without requiring extra virtual machines.

**3. Kubernetes Application Management**

- Helm: Packages and deploys applications into Kubernetes clusters.

- Kubectl: Official Kubernetes command-line tool used to manage clusters and applications.

**4. Cloud Deployment Tools**

| **Cloud Platform** | **Tools** | **Purpose** |
|----|----|----|
| AWS | AWS CLI | Manage AWS resources |
| AWS | eksctl | Create and manage Amazon EKS clusters |
| Azure | Azure CLI (az) | Manage Azure resources and Kubernetes clusters |

**5. Installing the Tools**

The course will demonstrate manual installation:

- Download applications from their official websites.

- Move executable files into a known directory.

- Add that directory to the system's PATH environment variable.

Package managers such as winget (Windows) and Homebrew (macOS) are alternatives.

**Overall Workflow**

The tools work together as follows:

1.  Podman runs containers.

2.  Kind creates local Kubernetes clusters.

3.  Kubectl manages Kubernetes clusters.

4.  Helm deploys applications.

5.  AWS CLI and eksctl manage AWS Kubernetes deployments.

6.  Azure CLI manages Azure deployments.

Main takeaway: These tools will help you develop, test, deploy, and manage Kubernetes applications locally and in cloud environments without having to pay for cloud resources during initial development.
