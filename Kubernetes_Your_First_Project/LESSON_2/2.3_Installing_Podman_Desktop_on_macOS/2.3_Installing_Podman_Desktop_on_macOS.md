# 2.3 Installing Podman Desktop on macOS

**Installing Podman Desktop on macOS**

This lesson explains how to install and configure Podman Desktop on a Mac so you can run containers for Kubernetes development.

**1. Download Podman Desktop**

1.  Open a web browser.

2.  Visit [<u>Podman Desktop official website</u>](https://podman-desktop.io/?utm_source=chatgpt.com).

3.  Click Download Now.

4.  Open the downloaded installation file.

**2. Install the Application**

1.  Double-click the downloaded file.

2.  Drag Podman Desktop into the Applications folder.

3.  Enter your Mac password if prompted.

4.  Press Command + E to close the installation window.

5.  Press Command + Space and search for Podman Desktop.

6.  Open the application.

**3. Configure Podman Desktop**

During the first-time setup wizard:

- Podman: Keep selected. It runs containers.

- kubectl CLI: Keep selected. It manages Kubernetes clusters.

- Compose: Optional; this course does not need it.

- Telemetry: Optional; choose whether to share usage information.

Click Start Onboarding.

**4. Install Podman Runtime**

1.  Click Next when Podman is not found.

2.  Select Yes to install Podman.

3.  Accept the license agreement.

4.  Click Install.

5.  Enter your Mac password if requested.

6.  Keep automatic startup enabled.

**5. Create a Podman Machine**

Podman needs a lightweight virtual machine to run its container engine.

1.  Click Next.

2.  Leave the default CPU and memory settings.

3.  Click Create.

4.  Wait for the virtual machine to finish starting.

**6. Install Kubectl**

1.  Click Next when prompted to install kubectl.

2.  Allow it to download.

3.  Enter your password to install it.

4.  Click Next to finish onboarding.

**7. Verify Podman Desktop**

Look for the Podman icon in your Mac system tray.

Ready

A green status indicator means your Podman machine is running.

**8. Test Podman Using Terminal**

Open Terminal and run:

```bash
podman
```

This should display the available Podman commands.

Next, run:

```bash
podman run --rm hello-world
```

If you see the Hello World message with three ASCII seals, Podman is successfully running containers.

**9. Optional: Use Docker Commands**

If you are familiar with Docker, you can create an alias:

```bash
alias docker=podman
```

Now you can use:

```bash
docker run --rm hello-world
```

This allows you to use familiar Docker commands through Podman.

**Important Things to Remember**

| **Tool**       | **Purpose**                                 |
|----------------|---------------------------------------------|
| Podman Desktop | Desktop application for managing containers |
| Podman         | Runs containers                             |
| Podman Machine | Lightweight virtual machine                 |
| kubectl        | Manages Kubernetes clusters                 |
| Compose        | Runs groups of containers                   |

**Main takeaway:** Podman Desktop is installed, configured, and tested. You now have a working container environment on macOS that will be used throughout the Kubernetes course.
