# 2.7 Installing Helm

**Installing Helm**

This lesson explains how to install Helm on macOS and Windows.

Helm is a Kubernetes package manager. It makes it easier to install, configure, and manage applications inside Kubernetes clusters without manually creating every Kubernetes resource.

**1. Install Helm on macOS**

1.  Open your browser.

2.  Visit [<u>Helm official website</u>](https://helm.sh/?utm_source=chatgpt.com).

3.  Click Get Started.

4.  Select Installing Helm.

5.  Find the desired Helm version.

6.  Download the correct version for your Mac:

    - macOS ARM64: Apple Silicon (M1, M2, M3, etc.).

    - macOS AMD64: Intel processors.

**2. Extract the Downloaded File**

Open Terminal and run:

```bash

tar -xvf helm-darwin-arm64.tar.gz

```

The extracted folder contains the Helm executable.

Move Helm into the system PATH directory:

```bash

sudo mv darwin-arm64/helm /usr/local/bin

```

Remove the unnecessary extracted folder:

```bash

rm -r darwin-arm64

```

Note: Use darwin-amd64 instead if you have an Intel Mac.

**3. Handle macOS Security Restrictions**

macOS may block Helm because it cannot verify the downloaded application.

To allow it:

1.  Open System Settings.

2.  Select Privacy & Security.

3.  Find the message indicating Helm was blocked.

4.  Click Allow Anyway.

5.  Return to Terminal.

6.  Run helm version again.

7.  Select Open Anyway if prompted.

8.  Enter your password if requested.

The instructor also recommends checking the downloaded file's checksum against the official Helm checksum to verify its integrity before allowing it to run.

**4. Verify Helm on macOS**

Run:

```bash

helm version

```

If version information appears, Helm is installed successfully.

**5. Install Helm on Windows**

1.  Visit [<u>Helm official website</u>](https://helm.sh/?utm_source=chatgpt.com).

2.  Select Get Started and then Installing Helm.

3.  Download the correct Windows version:

    - Windows ARM64: ARM processors.

    - Windows AMD64: Intel or AMD x86-64 processors.

4.  Open PowerShell.

**6. Extract Helm Using PowerShell**

Run the following command, replacing the example ZIP filename with your downloaded file's actual path:

Expand-Archive -DestinationPath "\$env:USERPROFILE\Apps" -Path "C:\Users\YourUsername\Downloads\helm-windows-amd64.zip"

This extracts Helm into your Apps directory.

**7. Move Helm into the Apps Directory**

The extracted files will be inside a folder called windows-amd64.

Move the Helm executable:

```powershell

Move-Item "\$env:USERPROFILE\Apps\windows-amd64\helm.exe" "\$env:USERPROFILE\Apps\helm.exe"

```

Remove the unnecessary extracted directory:

```powershell

Remove-Item "\$env:USERPROFILE\Apps\windows-amd64" -Recurse -Force

```

**8. Verify Helm on Windows**

Run:

```powershell

helm version

```

If you see version information, Helm is successfully installed.

**Important Commands to Remember**

| **Command**    | **Purpose**                                |
|----------------|--------------------------------------------|
| helm version   | Checks the installed Helm version          |
| tar -xvf       | Extracts compressed files on macOS         |
| sudo mv        | Moves files with administrator privileges  |
| rm -r          | Removes a directory on macOS               |
| Expand-Archive | Extracts ZIP files in PowerShell           |
| Move-Item      | Moves files in PowerShell                  |
| Remove-Item    | Deletes files or directories in PowerShell |

**Final Checklist**

- Download the correct Helm version.

- Extract the downloaded archive.

- Move helm or helm.exe into the Apps/PATH directory.

- Remove unnecessary extracted folders.

- Handle macOS security restrictions if applicable.

- Run helm version.

- Confirm Helm is installed successfully.

**Main takeaway:** Helm is installed on both macOS and Windows and is ready to help deploy and manage applications inside Kubernetes clusters.
