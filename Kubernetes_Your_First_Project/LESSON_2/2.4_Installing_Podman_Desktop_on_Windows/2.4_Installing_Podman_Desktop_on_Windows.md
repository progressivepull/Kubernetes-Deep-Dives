# 2.4 Installing Podman Desktop on Windows

**Installing Podman Desktop on Windows**

This lesson explains how to install and configure Podman Desktop on Windows so you can run containers for Kubernetes development.

**1. Download Podman Desktop**

1.  Open your web browser.

2.  Visit [<u>Podman Desktop official website</u>](https://podman-desktop.io/?utm_source=chatgpt.com).

3.  Click Download Now.

4.  Download the Windows installer.

5.  Open the downloaded installer.

6.  Allow local network permissions if prompted.

**2. Install Podman**

1.  Open Podman Desktop.

2.  Click Setup.

3.  Click Next to install Podman.

4.  Click Yes when prompted.

5.  Select WSL (Windows Subsystem for Linux) as the virtualization provider.

6.  Click Install.

7.  Click Close when installation finishes.

**3. Configure Podman Machine**

1.  Leave the Autostart option enabled.

2.  Click Next.

3.  Click Create to create your Podman machine.

4.  Wait for the machine to finish creating.

5.  Close the WSL information window.

6.  Click Next to continue.

The Podman machine is a lightweight virtual machine that runs the container engine.

**4. Install Kubectl**

Kubectl is needed to manage Kubernetes clusters.

1.  Open Podman Desktop.

2.  Click Settings.

3.  Find the kubectl section.

4.  Click Setup.

5.  Click Next to download and install kubectl.

6.  Finish the installation.

**5. Verify Podman Desktop**

Look in the lower-right corner of your Windows taskbar.

- Find the Podman hexagonal icon.

- Hover over it to check its status.

- Right-click the icon.

- Verify that the Podman machine has a green indicator.

Ready

Podman Desktop is running.

**6. Test Podman in PowerShell**

Open Windows Terminal or PowerShell.

First, enter:

```bash
podman
```

You should see the available Podman commands.

Next, run:

```bash
podman run --rm hello-world
```

If you see the Hello World message with three ASCII seals, Podman is working correctly.

**7. Optional: Create a Docker Shortcut**

If you prefer Docker commands, enter:

```bash
Set-Alias -Name Docker -Value Podman
```

Now test it:

```bash
docker run --rm hello-world
```

You should receive the same Hello World message.

Note: This alias applies only to the current PowerShell session.

**Important Things to Remember**

| **Component**  | **Purpose**                                      |
|----------------|--------------------------------------------------|
| Podman Desktop | Manages containers through a graphical interface |
| Podman         | Runs containers                                  |
| WSL            | Provides the Linux environment                   |
| Podman Machine | Runs the Podman container engine                 |
| Kubectl        | Manages Kubernetes clusters                      |
| Docker Alias   | Allows Docker commands to use Podman             |

**Final Checklist**

- Download and install Podman Desktop.

- Select WSL as the virtualization provider.

- Install Podman.

- Create the Podman machine.

- Enable Autostart.

- Install kubectl.

- Verify the green Podman status indicator.

- Run the Hello World container successfully.

Main takeaway: Podman Desktop is now installed and working on Windows. You have a container environment ready for Kubernetes development.
