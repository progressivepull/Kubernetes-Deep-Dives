You are a developer that is using Kubernetes locally for the first time. You want a tool that will make it easy to create Kubernetes clusters locally. Which of these options will accomplish this?

- A. Docker Desktop

- B. Kind

# Question 2

You want to run a container on a machine that has Podman installed. However, running docker run results in the error below: docker: command not found Which of these solutions will most easily fix this error?

- **A. Run alias docker=podman in your terminal, as Podman accepts all common Docker commands. (Correct)**

- B. Install Docker Desktop from your operating system's package manager.

- C. SSH into the underlying VM used by Podman Desktop and run the command there.

- D. Install Docker from your operating system's package manager.
