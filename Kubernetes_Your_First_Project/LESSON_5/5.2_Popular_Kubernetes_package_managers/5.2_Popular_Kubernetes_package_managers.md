# 5.2 Popular Kubernetes package managers

**Popular Kubernetes package managers**

**Kustomize**

- This lets you deploy “patches” on top of existing YAML files

- Great alternative for complex resources that would be cumbersome to turn into a Helm chart

- You can use Helm and Kustomize together to patch Helm charts

- Tools like ArgoCD and Flux work natively with Kustomize, making it a good choice for infrastructure management

- kustomize.io

**Carvel**

- A suite of tools that work together to create almost-immutable Kubernetes "packages"

- Carvel is like **rpm** or **aptitude**, for any Linux admins in the course

- It's more involved than Helm but an excellent choice for security-minded developers who want to bundle everything an application will need to run within a Kubernetes cluster

- You can use Helm and the Carvel suite together to add immutability to an existing Helm chart

- carvel.dev
